# Task1 — 图像拼接（Image Stitching）

选做实验 Task1 的实现与结果。对 `../Task1/` 下 4 组同场景左右视图（`imgN_L` / `imgN_R`）做拼接。

## 运行

```bash
cd task1_stitching
python3 src/stitch.py
```

依赖：`opencv-python`、`numpy`（仅用 SIFT / BFMatcher / 图像采样等基础接口；
**RANSAC 与 DLT 单应矩阵估计为本项目自行实现**）。

## 方法

| 步骤 | 做法 |
|---|---|
| 特征 | SIFT（`nfeatures=4000`），对尺度/旋转不变，可处理各组左右视图**分辨率不同**的情况 |
| 匹配 | 暴力匹配 + Lowe 比值检验（ratio = 0.75），右图 → 左图 |
| 几何 | **自实现 RANSAC + DLT**：Hartley 归一化 → SVD 解 8 参数 → 对称转移误差作内点判据 → 自适应迭代次数提前终止 |
| 变换 | 以左图为参考帧，右图经透视变换投影；画布自动求并集 |
| 融合 | 距离变换羽化加权（重叠区按到各自边界的距离加权平均），去除拼接缝 |
| 后处理 | 裁掉四周全黑边 |

## 结果

| 组 | 左图 | 右图 | 输出 | 匹配数 | 内点 | 内点率 | RMSE | 耗时 |
|---|---|---|---|---|---|---|---|---|
| img1 | 848×964 | 915×964 | 1539×968 | 186 | 149 | 80.1% | 0.33 px | 373 ms |
| img2 | 562×602 | 513×602 | 803×607 | 595 | 565 | 95.0% | 0.40 px | 72 ms |
| img3 | 866×435 | 975×436 | 1631×441 | 337 | 327 | 97.0% | 0.72 px | 88 ms |
| img4 | 518×408 | 558×408 | 832×419 | 296 | 272 | 91.9% | 0.62 px | 44 ms |

**4 组全部拼接成功**：内点率 80%–97%，内点重投影 RMSE 均 < 0.8 px（亚像素级配准精度），
拼接结果中未见明显拼接缝或鬼影。

场景内容：校园步道夜景（img1）、会议室（img2）、校园草坪与篮球场（img3）、室内休息区（img4）。

## 说明

- 各组左右视图的**尺寸不一致**（例如 img1：848×964 vs 915×964，img3：866×435 vs 975×436），
  说明存在尺度/拍摄距离差异；SIFT 对此天然不变，因此未做预缩放。
- RANSAC 采用自适应迭代：内点率足够高时立即停止，实际只需 4–14 次迭代即可收敛。
